# ShopQA 核心手工用例

| 编号 | 场景 | 前置条件 | 操作 | 预期结果 |
| --- | --- | --- | --- | --- |
| ORD-001 | 正常下单 | 用户已登录，商品库存充足 | 提交 1 件商品 | 返回 201，订单状态为 pending，库存扣减 1 |
| ORD-002 | 数量为 0 | 用户已登录 | 提交数量 0 | 返回 422，不创建订单，库存不变 |
| ORD-003 | 超过库存 | 用户已登录，库存为 2 | 提交数量 3 | 返回业务错误，不创建订单，库存不变 |
| ORD-004 | 未登录下单 | 无认证信息 | 调用下单接口 | 返回 401 |
| AUTH-001 | 重复注册 | 邮箱已存在 | 使用相同邮箱注册 | 返回冲突提示，不产生重复用户 |
| AUTH-002 | 普通用户访问管理接口 | 普通用户已登录 | 调用商品管理接口 | 返回 403 |

这些用例与自动化测试互补，面试时可说明如何从风险、等价类和边界值拆解测试范围。
