# ShopQA 测试计划

## 项目范围

ShopQA 是一个带有用户认证、商品管理和订单流程的 FastAPI 电商后端。本项目基于开源后端模板进行测试工程改造，新增的重点是测试场景、数据隔离、回归标记和持续集成说明。

## 测试重点

- 认证：注册、重复注册、登录成功与失败、未登录访问。
- 商品：列表查询、分页边界、管理员权限。
- 订单：库存不足、商品不存在、订单归属、订单汇总。
- 数据一致性：下单后库存扣减、订单金额快照和订单状态。

## 用例设计方法

- 等价类：有效用户/无效用户、有效商品/不存在商品。
- 边界值：数量为 0、负数、超过库存、分页参数边界。
- 权限矩阵：普通用户、管理员、未认证用户。
- 状态验证：订单创建后的状态和库存变化必须同时满足预期。
